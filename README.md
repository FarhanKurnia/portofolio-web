# Farhan Kurnia - Backend Developer Portfolio

Welcome to my personal portfolio website! This project showcases my work, skills, and experience as a Backend Developer. It's built with modern web technologies to provide a smooth and interactive user experience.

## 🚀 Live Demo
Check out the live version here: [farhankurnia.github.io](https://farhankurnia.github.io/portofolio-web/)

## 🛠️ Tech Stack

This portfolio is built using:
- **Frontend Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Routing:** [React Router 7](https://reactrouter.com/)
- **Icons:** [Lucide React](https://lucide.dev/) (via custom SVG implementation)

## ✨ Features
- **Responsive Design:** Fully optimized for all screen sizes (Mobile, Tablet, Desktop).
- **Interactive UI:** Smooth scroll animations and hover effects powered by Framer Motion.
- **Project Gallery:** Detailed showcase of my professional and personal projects.
- **Skills Section:** Comprehensive breakdown of my technical expertise in Backend, Frontend, and Tools.
- **Downloadable Resume:** Direct access to my latest CV.
- **Dark/Light Mode Ready:** Base structure supports theme transitions.

## ⚙️ Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FarhanKurnia/portofolio-web.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portofolio-web
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```

## 🚀 Deployment

This project is configured for easy deployment to GitHub Pages:
```bash
npm run deploy
```
This command will build the project and push the `dist` folder to the `gh-pages` branch.
